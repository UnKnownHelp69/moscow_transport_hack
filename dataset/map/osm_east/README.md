# Выгрузка OSM: восточная конечная

Данные © участники OpenStreetMap, лицензия ODbL 1.0 (https://www.openstreetmap.org/copyright).

Запрос: https://api.openstreetmap.org/api/0.6/map?bbox=37.456,55.807,37.466,55.814
(URL и время выгрузки в `provenance.json`).

- `raw.osm` - исходный ответ API;
- `raw.json` - трамвайные пути: ID узлов, версии, координаты;
- `tram.geojson` - те же пути для просмотра.

`analysis/east_map.py` совмещает кольцо 236632725 -> 236632736 -> 1232873047 -> 448224397 ->
409746401 с маршрутами train жёстким преобразованием. Совмещение принимается, только если
RMS <= 3 м, поворот <= 5° и сдвиг <= 10 м.
