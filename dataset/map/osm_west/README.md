# Выгрузка OSM: западная конечная (Таллинская)

Данные © участники OpenStreetMap, лицензия ODbL 1.0 (https://www.openstreetmap.org/copyright).

Запрос: https://api.openstreetmap.org/api/0.6/map?bbox=37.385,55.797,37.394,55.802
(выгружено 2026-09-26T13:17:03 UTC, подробности в `provenance.json`). Область выбрана по GNSS
train-прогонов у конечной.

- `raw.json` - пути `railway=tram`: ID узлов, теги, версии, исходные координаты;
- `tram.geojson` - те же пути для просмотра.

`analysis/build_osm_route.py` достраивает по выгрузке кольцо, которое train-прогоны покрывают
только частично:
- входящий путь 3 (`188726185`) и обратный путь 4 (`188726177`) определены по train;
- геометрия OSM совмещена с ними жёстким преобразованием (последние 70 м входящего и первые
  80 м обратного пути): RMSE по XY 0.28 м, поворот 0.23°, сдвиг (0.42, 0.49) м;
- высота соединения интерполируется между наблюдаемыми в train концами (в OSM высоты нет);
- `--extend-prefixes` добавляет ~93 м пути OSM перед началами обратных путей, чтобы старт внутри
  конечной проецировался на маршрут с верным направлением.

Train-данным одинаково соответствуют два варианта кольца: внутреннее (путь `188726176`,
соединение ~130 м) и внешнее (`188726180`, `1199696832`, `1232873046`, ~156 м). В поставляемой
модели внешнее (`--topology outer`), выбрано по прогонам val.
