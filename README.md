# mos_trap: резервная одометрия беспилотного трамвая

Решение кейса «Резервная одометрия по модели» хакатона Московского транспорта. Пакет ROS 2
Humble оценивает скорость и положение трамвая **без GNSS и IMU**: по скоростям двух тележек
и позиции контроллера водителя. GNSS используется только для начальной выставки в первые 3 с.

**Результаты:**

| проверка | RMSE положения 3D | RMSE скорости |
|---|---|---|
| чекер организаторов, bag `30618_88aea4d9` (не входил в калибровку), ROS 2 | **1.5-1.7 м** | **0.049 м/с** |
| 30 отложенных рейсов (val, ~160 км), среднее / медиана / худший | **1.65 / 1.36 / 4.18 м** | 0.046 м/с |
| 30 рейсов калибровки (train), среднее / медиана | 1.33 / 0.90 м | 0.061 м/с |

- Медиана дрейфа в конце рейса - 0.013 % пути.
- Выход 40 Гц, задержка 0.34 мс (максимум 12.5 мс), CPU 3.4 % одного ядра, память 99 МБ.
- Модель откалибрована только по train; val использовался для выбора вариантов модели.

## Быстрый старт

Сборка в workspace чекера организаторов:

```bash
cd /workspace/src && git clone https://github.com/UnKnownHelp69/moscow_transport_hack.git mos_trap
cd /workspace && source /opt/ros/humble/setup.bash && colcon build && source install/setup.bash
src/mos_trap/scripts/run_with_checker.sh bags/30618_88aea4d9
```

Сборка отдельно (без чекера) и запуск вручную - в [`ДЛЯ_ЖЮРИ.md`](%D0%94%D0%9B%D0%AF_%D0%96%D0%AE%D0%A0%D0%98.md).

## Структура репозитория

```
tram_odometry/           ROS 2-пакет решения
  tram_odometry/         estimator.py (ядро без ROS), node.py, eval_node.py, route.py, geo.py
  tram_odometry/data/    калибровка: маршруты, станции-маяки, модель тяги, масштабы колёс
  config/params.yaml     все параметры; launch/; test/ (юнит-тесты ядра)
tram_vehicle_msgs/       сообщения (VelocitySensor, DriverControllerCommand)
analysis/                сборка модели (build_model.py), оценка (evaluate.py), сбои (robustness.py)
dataset/map/             официальные центрлинии пути (MGRS 37U) и архив OSM; bag-файлы не в git
docs/                    модель, допущения и параметры, точность, ограничения и план, график
ДЛЯ_ЖЮРИ.md              инструкция для жюри
scripts/                 run_with_checker.sh, demo_play_bag.sh, fetch_data.sh
```

bag-файлы для офлайн-оценки загружает `scripts/fetch_data.sh` из ветки `data`
в `dataset/data/` (или задайте путь через `MOS_TRAP_DATA=/path`).
