# Допущения, ограничения модели и параметры

Критерий: перечень допущений и ограничений, описание конфигурируемых параметров. Сама модель -
[МОДЕЛЬ.md](%D0%9C%D0%9E%D0%94%D0%95%D0%9B%D0%AC.md).

## 1. Допущения и ограничения модели

- Трамвай ездит по известной линии: официальная карта, конечные достроены по train и OSM.
  На другой линии нужны её карта и сбор станций.
- Движение только вперёд: колёса не дают знака скорости, отрицательных скоростей в данных нет.
- Эталон - `base_link`: ось передней тележки на уровне рельса, по tf антенн от организаторов.
- Модель тяги усреднена по вагонам и загрузке. Масса и уклон не оцениваются, они входят в
  остаток 0.21 м/с².
- Станции и геометрия конечных выучены по записям. Новое место остановки или новый путь на
  конечной не будут использованы.
- Ветка на западной конечной определяется по скорости. Если водитель поедет в тупик медленнее
  5 м/с, модель останется на кольце, и в последние десятки секунд рейса ошибка составит
  десятки метров.
- Синхронное проскальзывание обеих тележек обнаруживается, но компенсируется лишь частично.
- Нужна выставка: GNSS в первые секунды или ручная начальная позиция.

## 2. Конфигурируемые параметры

Все параметры с комментариями - в [`tram_odometry/config/params.yaml`](../tram_odometry/config/params.yaml).

| параметр | по умолчанию | смысл |
|---|---|---|
| `vehicle_id` | `''` | номер вагона → масштаб колёс из `data/vehicles.json` |
| `wheel_scale` | 1.0 | масштаб колёс вручную (эквивалент радиуса колеса) |
| `initial_x`, `initial_y`, `initial_yaw` | NaN | начальная позиция (MGRS 37U local, м; курс, рад), если нет GNSS |
| `gnss_wait` | 10 с | сколько ждать GNSS до ручной позиции |
| `init_window` | 3 с | окно GNSS для выставки |
| `use_model` | true | модель тяги в прогнозе скорости |
| `accel_std` | 0.3 (м/с)/√с | шум процесса модели тяги |
| `wheel_std` | 0.05 м/с | шум датчика скорости |
| `agree_tol` | 0.5 м/с | порог согласия тележек |
| `gate_min`, `gate_sigma` | 0.7 м/с, 4 | допуск одиночной тележки |
| `slip_accel_max`, `spin_margin` | 6.0, 1.5 м/с² | пороги юза и буксования |
| `slip_window` | 0.3 с | окно оценки ускорения колеса |
| `recover_time` | 2 с | сколько модель может перекрывать колёса |
| `wheel_timeout`, `input_lag_tol` | 0.5, 0.5 с | устаревание показаний; допустимое опоздание между топиками |
| `distance_innovation_gain`, `distance_innovation_max_dt` | 0.5, 0.2 с | поправка пути трапецией ([МОДЕЛЬ.md](%D0%9C%D0%9E%D0%94%D0%95%D0%9B%D0%AC.md) §5); 0 - выкл. |
| `stop_dwell`, `stop_speed` | 5 с, 0.3 км/ч | признак стоянки |
| `stop_meas_std` | 1 м | точность станции |
| `stop_gate_min`, `stop_gate_sigma` | 5 м, 3 | допуск ассоциации со станцией |
| `stop_repeat_dist` | 50 м | повторное использование станции |
| `queue_mode`, `queue_prior` | `soft`, 1.0 | места очередей: `off` / `skip` / `soft`, априорный вес |
| `anchor_scale`, `anchor_scale_std`, `anchor_deadband` | вкл., 0.005, 0.2 % | масштаб пути по станциям |
| `drift_rate` | 0.3 % | рост `σ_s` с пройденным путём |
| `branch_speed`, `branch_start`…`branch_window` | 5.0 м/с, 20…200 м | выбор ветки на западной конечной |
| `init_max_xt`, `init_fallback_xt` | 8, 40 м | допуски привязки при выставке |
| `init_edge`, `init_fallback_std` | 15, 30 м | сомнительная выставка → широкая начальная `σ_s` |
| `along_mode` | `kf` | `kf` - одна гипотеза, `pf` - фильтр частиц по (s, масштаб) |

Данные модели в `tram_odometry/tram_odometry/data/`: `routes.json`, `stops.json`,
`traction.json`, `vehicles.json`. Они построены только по train-прогонам и архиву OSM,
пересборка - `python3 analysis/build_model.py` (результат побайтно совпадает с поставляемым).
